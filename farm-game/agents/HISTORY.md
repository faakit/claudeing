# What the docs cleanup removed

On 2026-10-11 the branch `docs/cleanup` removed the history that five rounds of parallel agents had left in the
repo. Git still has all of it. Every file below is unchanged at commit **`62fde3c`**, the tip of
`integration/round4-2026-10-11`, which is the last commit that had it.

To read one file, or to restore a folder:

```sh
git show 62fde3c:farm-game/agents/PLAN-CONTROLS.md
git restore --source 62fde3c -- farm-game/agents/critiques/controls-critic
```
