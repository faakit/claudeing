# Art session 2026-10-08 (checkpoint before the depth merge)

Branch `art/atlas`. Everything below was checked only in **headless Chromium screenshots** (1x = 200x400 canvas,
phone = 390x844 CSS px at DPR 2). Nobody has looked at it on a real phone yet.

## What landed

- **Manifest** `agents/out/art-manifest.md`, printed by `node art-src/tools/manifest.mjs` from `src/art/manifest.ts`.
  Keys come from the data (items, tools, placeables, animals, crops, trees, nodes, npcs), so keys added on the depth
  branch show up after the merge (they fall back to placeholders until art is made).
- **Loader** `src/art/atlasLoader.ts`: `world`, `ui`, `chars` atlases + `tilesets/tiles.png` (same tile order as
  `placeholder`). Each texture key becomes a view on the shared atlas GPU texture (call sites unchanged); partial
  coverage or the Canvas renderer paints over the generated canvas; anything missing keeps its generated placeholder.
  A missing key logs a console error (e2e fails on it). `src/art/atlases.json` lists which files exist.
- **Test** `tests/art.test.ts`: every manifest key resolves to an atlas frame of an allowed size or to a generated
  fallback (the generators run against a fake scene); no orphan atlas frames; tileset size; roof decor layout.
- **Pipeline** `art-src/tools/`: `extract.py` (Flow sheet to per-sprite crops), `pixelart.py` (chroma key,
  components, native pixel-grid detection, per-cell median, coverage-weighted mode downscale over palette indices,
  island cleanup, fresh 1 px outline in the darkest palette brown), `authored.py` (terrain, soil, seed mound, roofs,
  ground decor, UI glyphs from palette indices), `build.py` (all PNGs, packed atlases, tileset, palette),
  `shots.mjs` (staged review screenshots), `prompts_md.py`. Rebuild: `python art-src/tools/build.py`.
- **Code touched outside src/art**: `PreloadScene` (load + apply + villager idle anims), `NpcRenderer` (villagers use
  their own `npc_<id>` sheets with a 2-frame idle instead of the tinted player; the non-integer breathing tween is
  gone), `ObjectsRenderer` (animals at native size with a 2-frame idle when art exists), `WorldScene` (one call: roofs
  and ground decor derived from the map, no map file changes), `eslint.config.js` (node globals for art-src).
